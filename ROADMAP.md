# Roadmap to a larger knowledge workspace

## Shipped in 0.1

Linked Markdown notes, basic metadata, cloud persistence, revision conflict protection, daily journals, search, library/table views, graph, visual canvas, templates, attachment upload, recoverable trash, content history, export/import, companion customization, focus timer, and spaced self-review.

## Next: reliability and scale

- Per-note D1 records, pagination, full-text search, bounded server request streaming.
- Conflict resolution UI and multi-device integration tests.
- Attachment-inclusive ZIP backups with restoration and garbage collection.
- Full mobile browser and accessibility audits; complete keyboard canvas controls.
- PWA offline cold-start and synchronization queue.
- Component extraction and end-to-end browser tests.

## Knowledge features

- Named reading trails and richer typed properties.
- Arbitrary filtered database views, formulas, and Kanban boards.
- Stronger Markdown/CommonMark fidelity, full YAML frontmatter, block references, embeds, math, diagrams, and PDF annotations.
- Visual research desk and web clipping.
- Optional sourced note Q&A, semantic search, and question generation with explicit provider consent.

## Long term

Local directory vault access, JSON Canvas interoperability, extension APIs, audio capture, published notebooks, and platform-specific desktop/mobile packages. Obsidian plugin compatibility is not promised.
